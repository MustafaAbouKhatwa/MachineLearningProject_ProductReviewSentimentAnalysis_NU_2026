2. CUDA Verification

Run the following in Python:

import torch
print(torch.version.cuda)          # Expected: 12.x or 13.0
print(torch.cuda.is_available())   # Expected: True
print(torch.cuda.get_device_name(0))  # Expected: NVIDIA GeForce RTX 3060


Output on this system (Can be CUDA 12.4 and above):

    CUDA available: True

    GPU detected: NVIDIA GeForce RTX 3060

-------------------------------------------------------------------------------------------------------------

3. Virtual Environment Setup (VENV)

Create and activate a virtual environment:

$ python -m venv projectname
$ source projectname/bin/activate   # On Linux/Mac
# On Windows use: projectname\Scripts\activate

Install kernel support:

(venv) $ pip install ipykernel
(venv) $ ipython kernel install --user --name=<venv-name>

-------------------------------------------------------------------------------------------------------------

4. Install Dependencies

Make sure you have a requirements.txt file in the project root. Then run:

(venv) $ pip install -r requirements.txt
